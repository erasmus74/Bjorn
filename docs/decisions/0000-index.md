# Architecture Decision Records (ADRs)

Decisions relevant to the v2 effort. Numbered sequentially; once written, an ADR is immutable — supersession happens via a new ADR that references the prior one.

## Format

```
# ADR NNN: Title

- Status: Proposed | Accepted | Superseded by NNN | Deprecated
- Date: YYYY-MM-DD

## Context
(Why this decision is being made now)

## Decision
(What we decided)

## Consequences
(Positive, negative, neutral effects)
```
